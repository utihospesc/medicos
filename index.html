⚙ Configure o Firebase para ativar a nuvem

Para salvar os dados na nuvem e compartilhar entre todos os médicos, configure um projeto Firebase gratuito.

Passo a passo:

1. Acesse console.firebase.google.com e crie um projeto

2. Ative Firestore Database (modo de produção)

3. Ative Authentication → E-mail/senha

4. Vá em Configurações do projeto → Seus apps → App da Web

5. Copie as configurações e cole no início do index.html em FIREBASE_CONFIG

6. Cadastre os médicos em Authentication → Usuários
